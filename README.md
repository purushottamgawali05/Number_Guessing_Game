# Number Guessing Game

A simple and fun command-line number guessing game built with Python. Challenge yourself to guess a randomly generated number!

## 🎮 How to Play

1. Run the game: `python game.py`
2. The computer generates a random number between 1 and 50
3. Enter your guess when prompted
4. The game will tell you if your guess is too high or too low
5. Keep guessing until you find the lucky number
6. Win by guessing correctly!

## 📋 Features

- Random number generation between 1 and 50
- Real-time feedback on guesses (too high/too low)
- Simple and interactive command-line interface
- Continuous gameplay until you win

## 🛠️ Requirements

- Python 3.x
- No external dependencies

## 📝 Usage

```bash
python game.py
```

Example gameplay:

```
Enter your number: 25

Enter your number: 40

Enter your number: 35
```
